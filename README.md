# 기울여 넘기기 실험 (HCI 3팀)

누운 자세에서 숏폼을 넘기는 세 방식(엄지 스와이프 / 고정 기울기 / 적응 기울기)을 비교하는 실험용 웹앱입니다.

## 파일
- `index.html` — 실험 화면: 설정 → 캘리브레이션 → 연습 → 본 실험 → 설문 → 결과·저장
- `tilt-core.js` — 기울기 계산과 넘김 판정 엔진. 화면과 분리되어 있어 Node로 테스트할 수 있음
- `test-core.js` — 엔진 시나리오 테스트 16개 (`node test-core.js`)

## 쓰는 법
- 아이폰 Safari에서 HTTPS 주소로 엽니다. 기울기 센서는 HTTPS에서만 켜집니다.
- 화면 세로 고정을 켭니다.
- '센서 켜고 시작'을 누르고 '동작 및 방향' 접근을 허용합니다.
- 컴퓨터에서 시험할 때는 주소 끝에 `?sim`을 붙이면 시뮬레이터 패널이 뜹니다.
- 기록은 그 기기의 Safari에만 남습니다. 조건이 끝날 때마다 파일로 저장하세요. 저장 버튼을 누르면 공유 창이 뜨고, '파일에 저장'이나 AirDrop으로 옮기면 됩니다.

## 저장 파일 (모두 엑셀에서 바로 열리는 CSV)
| 파일 | 한 줄이 뜻하는 것 | 주요 열 |
|---|---|---|
| `tiltflick_summary_*.csv` | 조건 하나 | 정확히 넘김, 놓침, 잘못 넘김, 오작동, 반응 시간, NASA-TLX, 조작감, 센서 종류·Hz, 실험자 메모 |
| `tiltflick_events_*.csv` | 사건 하나 (지시, 넘김, 놓침, 고쳐 잡기 지시, 기준 다시 잡기 등) | `t_ms`(조건 시작부터 ms), `type`, `cls`(hit/wrong/false), `rt_ms`, `afterRegrip`(1이면 고쳐 잡은 뒤 15초 안) |
| `tiltflick_samples_*.csv` | 기울기 측정 한 번 (초당 약 30번) | `pitch_deg`(앞뒤), `roll_deg`(옆), `speed_dps`(회전 속도), `state`(armed/cand/held) |

- 결과 화면의 **이 조건 CSV 저장**은 그 조건의 세 파일을 한 번에 저장합니다.
- 첫 화면의 **전체 요약 CSV 저장**, **전체 원자료 CSV 저장**은 그 폰에 쌓인 모든 조건을 한 파일로 모읍니다.
- 모든 파일에 `id`, `pid`, `posture`, `method` 열이 있어 폰 여러 대의 파일을 그대로 이어 붙여 분석할 수 있습니다.
- `백업용 JSON 저장`은 같은 내용을 한 파일에 담은 백업입니다.

## 기본 값
| 항목 | 값 |
|---|---|
| 넘김 각도 | 15° |
| 복귀 범위 | 8° 안으로 |
| 복귀 제한 시간 | 0.5초 |
| 넘긴 뒤 무시 시간 | 0.35초 |
| 옆 기울기 허용 | 앞뒤 기울기의 80%까지 |
| 적응형 기준 재설정 | 1초 동안 가만히 있을 때 |
| 가만히 판정 속도 | 캘리브레이션으로 개인별 4–15°/s |
| 본 실험 | 180초 |
| 고쳐 잡기 지시 | 60초, 120초 |
| 넘김 지시 간격 | 4–8초 (다음 80%, 이전 20%), 5초 안에 못 넘기면 놓침 |
